The critical path

One chain governs the date

Razorpay test keys → Sprint 3.5 build (~2 weeks) → admin Packages / Payments / Success Fees → full regression → launch

Razorpay is commonly misread as a configuration step. It is not — there is no payment code in the repo at all today. Once credentials arrive it is roughly two weeks of build plus test, and it cannot start early.

Working backwards from 15 September: release prep needs Week 5, admin completion needs Week 4, so the Razorpay build must run Weeks 2–3 — which means credentials by 17 August. Every week they slip moves launch by a week, because nothing else can fill that slot.

If they slip past 31 August, the realistic choice is to move the date or launch without payments — shipping the free tier and lead capture, with paid tiers as a fast-follow. That fallback is genuinely viable: everything except payments is already built and tested.
